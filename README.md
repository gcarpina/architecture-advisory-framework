# Architecture Advisory Instructions
A reusable AI instruction framework for:

- Principal Architects
- Software Architects
- Architecture Review Boards
- Technical Leaders
- Platform Architects

The framework focuses on:

- Architecture Reviews
- Solution Design
- Technical Governance
- Operational Excellence
- Decision Quality
- Architectural Sustainability

Its objective is not simply to generate answers, but to improve architectural decision quality through structured reasoning, risk identification, governance awareness, and independent review practices.
